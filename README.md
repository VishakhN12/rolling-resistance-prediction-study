

# Rolling Resistance Prediction Study

## Overview
A comparative study of rolling resistance prediction using statistical and machine learning models. The project analyzes the influence of key tire and vehicle parameters and evaluates different regression models for prediction accuracy.

---

## Objective
- Predict rolling resistance using data-driven methods
- Compare multiple machine learning models
- Identify key influencing parameters
- Evaluate model performance using standard metrics

---

## Dataset
The dataset contains tire parameters such as:
- Size
- Other tire parameters like Weights, PSI, load index, Dimensions, tested values like Stiffness(Lat.,Longi., Rad. & tor.) and also widths of belts as per your requirements.
- Rolling resistance at 80 or 60 km/h (as per requirementstarget variable)

---

## Models Used
- Linear Regression
- Random Forest Regressor

---

## Evaluation Metrics
- R² Score
- Mean Absolute Percentage Error (MAPE)

---

## Results
- Machine learning models outperform simple linear regression
- Ensemble models (Random Forest) provide better accuracy
- Feature importance highlights key influencing parameters
